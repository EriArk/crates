# Передача аркад и Brick Tanks — 25 октября 2026

Подготовка для основного чата. Ветка `codex/handheld-arcade-repair`, база `d88a855`.
Восемь общих аркад имеют версию 0.1.3, Pocket Artillery — 0.1.4.
Golf, каталог, опубликованные релизы и портативки в этом заходе не менялись.

## Доделано

- Девять игр: ограниченный внутренний Canvas, масштабируемый игровой HUD,
  полноэкранная сцена без служебных полос сверху/снизу, меню по вызову.
  Клавиатура, SDL-контроллеры и сенсорное управление сохранены.
- Brick Racing и Brick Tanks: LCD-палитра всего интерфейса, квадратные эффекты,
  двухцветные портреты SDK. Имена пакетов содержат Brick, постоянные ID сохранены.
- Racing: пять полос без разделителей, бесконечный переключаемый boost,
  три жизни, восстановление за 0,6 с; протокол `mini-racing.3`.
- Tanks: дуло по центру без передних угловых клеток, карта 61×45 с кирпичом,
  сталью, водой и кустами. Сеть показывает только камеру своего танка;
  couch на одном экране сохраняет две камеры.
- Tanks: 2–16 участников, авторитетная симуляция хоста, проверка владельца ввода,
  карта один раз и изменения до 15 Гц, общий реванш и закрытие матча при потере
  участника. Манифест `tanks.3`, `seats: 16`, capability `network.group: 1`.

[Подробная реализация и обоснование](../games/competitive-minigames/docs/handheld-repair.md).
Просмотренные кадры Linux находятся в `games/competitive-minigames/<id>/docs/play.png`;
они показывают локальный тестовый рендер, а не экран Odin/Flip.

## Стыковка с SDK и Lobby

SDK подготовлен отдельно: `D:\Projects\TrainerOs-sdk-group`, ветка
`codex/sdk-group-records`, база `59625d6`, коммит `59755fc1e1a72372a7eacbc4d439452781fcab70`.
Его `docs/SDK_GROUP_LOBBY_HANDOFF.md`
и `sdk/NETWORK.md` определяют контракт. Исходники Lobby здесь не изменены:
владелец дорабатывает его в другом чате.

Порядок интеграции: объединить SDK с работой Lobby → собрать оболочку для целевых
устройств → проверить установленный максимум мест → собрать/установить игры →
пройти Ready/Start, матч, реванш, выход и повторный запуск. Все участники должны
иметь совместимые протоколы. `seats` означает максимум, не обязательное заполнение.
Tanks нельзя публиковать для старого host без `network.group: 1`.

## Недоделано — основной чат и внешняя приёмка

- ARM64-сборки этого изменения, установка на Odin/Flip и публикация.
- Физические контроллеры, FPS/температура/память на портативках.
- Живой Fluxer, разные интернет-сети, группа реальных устройств и её upload.
- Встраивание в параллельно изменяемый Lobby и полный пользовательский путь.
- Live join и миграция хоста не реализованы: потеря участника завершает матч.
  У SDK до 15 helper-процессов на хосте; их стоимость требует аппаратного замера.

Linux x86_64 пакеты и исходники подготавливаются в
`dist/prepared-handheld-20261025/<id>/`; точные ревизии, SHA256 и проверка установки
фиксируются ниже после упаковки. Эти локальные артефакты не опубликованы.
