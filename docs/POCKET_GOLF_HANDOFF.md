## Текущая подготовка 0.1.7 — физика удара и качения

Исходники `73abba17b7912dda6bcad4616dd5b1da4b472ad4`, ветка

Архивы: `dist/prepared-pocket-golf-0.1.7/`. Предыдущие версии сохранены.

Исправлено торможение по направлениям: разброс 1,714 мм на 2,33 м для 72 углов.
Начальная скорость снижена до 0,84–8,4 м/с; песок тормозит сильнее газона.
Контакты у углов учитывают круглый мяч, отскок сохраняет касательную скорость.
Медленный центральный удар проваливается в чашу, сильный проходит над ней,
касание края отклоняет траекторию. Мяч вращается, отображение интерполируется
между 120 шагами в секунду, уменьшение при попадании заменено погружением.

[Подробности, параметры, кадры и журнал](../games/pocket-golf/docs/PHYSICS.md).
Поле пока плоское; прыжки, управляемое вращение и контакты между мячами не добавлены.
Следующий шаг после оценки ощущения удара — небольшие игровые уклоны с совпадающей
геометрией и физикой. Общий SDK-аватар/гардероб остаётся отдельной интеграцией.

**Сетевая совместимость изменена:** обеим сторонам требуется `pocket-golf.2`;
старый `pocket-golf.1` отклоняется. Хэш состояния содержит ревизию `rolling-2`.
Существующие Lobby и транспорт сохранены, новые сетевые сервисы не добавлены.

## Проверено

- Проверены SHA-256 всех четырёх архивов, ревизия в обоих records и побайтовое
  совпадение каждого файла архива исходников с зафиксированным проектом. Из этого
  архива заново собраны все три экспорта и выполнена упаковка без доступа к Git.
  Это проверка самостоятельной пересборки, не утверждение побайтовой идентичности
  повторных архивов с отличающимися метаданными упаковки.
- Правила, обработка некорректного протокола и полный UI-цикл на Windows/Linux.
  Windows Vulkan Mobile и Linux OpenGL/Xvfb просмотрены; журнал и снимки —
  [в подготовке игры](../games/pocket-golf/docs/PREPARATION.md).
- Два реальных Godot-процесса с PlatformHost/TLS: три лунки, одинаковый результат,
  взаимный реванш, отзыв профиля, сохранённое членство Lobby. Доставка provider
  signaling в тесте подменена; это не проверка Fluxer и разных домашних сетей.
- Точный x86_64-архив из таблицы установлен настоящим Crates installer в отдельном
  Linux-контейнере. Пройдены графический запуск через launcher, running lease,
  отказ удаления работающей игры, удаление и повторная установка с сохранением
  пользовательского файла. Контейнер работает без сети, с Xvfb/Mesa llvmpipe;
  производительность реального устройства этим не измерялась.
