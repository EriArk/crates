# Pocket Golf 0.1.20 — звук, джинглы и движения

25 октября 2026. Подготовительная ветка `codex/handheld-arcade-repair`, начало
этого изменения — `d013727`. Предыдущая игра — 0.1.19, протокол остаётся `pocket-golf.6`.
Работа с Lobby и SDK в этой поставке не выполнялась.

## Доделано

- Собственная 87-секундная спокойная островная композиция с зацикливанием.
  [Послушать Ogg](../games/pocket-golf/assets/audio/little-green.ogg).
- Джинглы обычной лунки, hole-in-one и завершения раунда; музыка приглушается
  под джинглом. Удары, отскоки, песок, качение, край/стакан лунки, шаги, меню.
- Sound в главном меню и паузе: независимые сохраняемые Music/Effects, 0 = mute.
  Фокус, локальная/онлайн-пауза, выход, ограничение голосов и старых событий.
- Переступание на существующем скелете SDK с опорной стопой и подъёмом второй.
  На непрерывном повороте 90°/с при 30/60/120 FPS максимальное расхождение
  голеностопа с целью IK составило 0,011875 м на тестовом SDK-образе.
- Три 2,8-секундных реакции на лунку: кулак, прыжок, танец; краткий вид на
  гольфиста, восстановление клюшки/стойки/выбранной камеры после реакции.

[Устройство, источники и лицензии](../games/pocket-golf/docs/AUDIO_MOTION.md).
В игру не добавлен GLB персонажа, внешняя модель использована только как локальная
тестовая fixture. Проверка `sync_avatar_sdk.py --verify` подтверждает неизменённую
официальную копию SDK `21008cf44a156d8214df3aa0f349a5b21ab28cad`.

## Проверено локально

Godot 4.7.2 stable. Windows: NVIDIA GTX 1660 Ti, Vulkan Mobile; Linux:
Ubuntu 24.04, Mesa llvmpipe/OpenGL Compatibility в отдельном контейнере без сети.
Linux — программный рендер, не измерение FPS на портативке.

изолированные результаты, физические кнопки этим не подтверждены.

## Сборки и следующий шаг

Экспорты Windows, Linux x86_64 и ARM64 подготовлены в `build/golf-audio-0.1.20`.
Пакеты, архив исходников и SHA256 будут зафиксированы после упаковки этой ревизии.
В основном чате достаточно перенести изменения Golf и соответствующие записи
документации, затем выполнить обычный процесс публикации, когда владелец продолжит.

## Недоделано / отложено владельцем

Портативки не подключались, обновление не устанавливалось, звук/FPS/контроллеры
на Odin/Flip не проверялись. Владелец сам сообщит, когда это разрешено.
Публикация и push не выполнялись. Остаются прослушивание и оценка музыки/анимаций
владельцем, физические устройства и свежий живой интернет-матч. ARM64-экспорт
подтверждает только создание файла, а не его запуск на устройстве.
