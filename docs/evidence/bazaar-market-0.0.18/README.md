# Festival Park counter on two handhelds

The [Odin 2 counter](odin-counter.jpg) and [purchase review](odin-purchase.jpg)
show the same live test offer. Ren approached Mika’s counter, activated the
focused row with the game’s accept action and cancelled the native review.
The same Pecha Berry was still available for 65 test Sparks afterwards. The
[asking price](asking-price.png) shows the native window during the 800×450
input test. Moving right raised 25 to 65 before confirming the listing.

Warframe’s approach to a displayed shop informed the walk-up interaction.
Guild Wars 2’s inventory-based selling and explicit costs informed the
stocking and price review. FFXIV’s controller market board informed the
focus and accept flow. [Warframe trading FAQ](https://support.warframe.com/hc/en-us/articles/37999066923533-Trading-FAQ-Safe-Trading-Tips) ·
[Guild Wars 2 Trading Post](https://www.guildwars2.com/en/news/introducing-the-new-trading-post/) ·
[FFXIV UI Guide](https://eu.finalfantasyxiv.com/uiguide/item/item-market/market_how_to.html).

## Item illustrations

The game and native checkout package the same two transparent, 192-pixel
illustrations. Their local catalogue matches the game and item names already
supplied by the profile inventory. Other items retain the inventory category icon
in the game. [Game assets](../../../games/bazaar/assets/market).

The built-in image generator produced an atlas with this prompt.

> A production game inventory sprite atlas on true transparent alpha, horizontal canvas with two equal square cells, no grid lines. Two separate illustrations ONLY. Left cell centered: a single plump round cobalt-blue fantasy berry, two small dimples, small pair of folded green leaves on top. Right cell centered: one pastel pink teardrop peach berry with a pointed bottom, patches of coral peach and two spring-green leaves atop. Both use the same hand-painted gouache JRPG provisions illustration style, sharply readable silhouettes, luminous pale edges, a few broad flat shaded planes, tactile cut-paper color blocks, tiny gleams, three-quarter view. Balanced generous space around each fruit. No outlines that look like sticker backing, no lettering, no gold, borders, panel, floor, shadows or scenery. Intended to be readable at 32px and attractive at 150px.
