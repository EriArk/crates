# Pocket Golf coastal art preview

[Comparison from the same three cameras](before-after.jpg). The desktop
OpenGL captures use the first hole in a local single-player game, at 900 × 506.
The overview shows the changing mowing direction and two beach picnic spots.
The lower views show the harbour light, archipelago, enamel rail and pin flag.

The island regression passed across the three greens, including canopy
clearance and grounding. Rules and camera tests passed. The Linux export was
also checked on the Vulkan Mobile renderer. The isolated island test reports
a resource still open on forced exit. The gameplay camera capture runs the
normal quit handler and exits cleanly.
