# Pocket Golf 0.1.24 — общий аватар, 28 октября 2026

Исходники игры: `47dcc38f867e0b0a7df820dd120e4c545cb8a8b5`.
Общий SDK: `f328d5a374193e78478805c28ed440832fbf4a36` из TrainerOS.
Модели остаются в установленном системном пакете revision 4; игра содержит
только клиентский код. [Инструкция для разработчика](https://github.com/EriArk/TrainerOS/blob/main/sdk/AVATAR_QUICKSTART.md).

## Проверено

- Godot 4.7.2 экспортировал Linux ARM64/x86_64 и Windows: [manifest](build-manifest.json).
  Чистый изолированный импорт и экспорты завершились без ошибок скриптов.
- Настоящий SDK host → сцена игры: [3 passed, 0 failed, 0 skipped](golf-host.txt),
  включая setup/cleanup. Новые глаза и две палитры, отдельный гость,
  изменение внешности после удара, немедленный отзыв личности и независимая
  жизнь локального аватара при отключении игровой сети.
- Одинаковый ARM64-пакет установлен через штатный Crates Store на Odin и Flip.
  Проверены размер/хеш и архитектура; предыдущие immutable objects сохранены.
  Игровые файлы, настройки, другие пакеты и бинарник оболочки не изменены установкой.
  На Flip сравнение `play_sessions` и профилей с резервной БД прошло;
  [квитанция установки](flip-installation.json).
- На Odin первоначальный контроль всей таблицы `adventures` остановился после
  успешной установки: shell обновляет версию библиотечной карточки при смене
  пакета. Сравнение защищённых файлов перед этим прошло. Отдельный снимок
  `play_sessions` до установки не сохранён, поэтому равенство этой таблицы
  на Odin не заявляется. Повторная установка/откат не требовались.
- На каждом устройстве запущен установленный пакет через managed launcher,
  в меню подтверждено Connected to TrainerOS; открыт Solo → Ready → вид от плеча.
  Видны сохранённый персонаж, одежда, волосы и оба портрета:
  [Odin / Mobile](odin.png), [Flip / Compatibility](flip.png).
- Проверены managed-процесс, отсутствие ошибок Godot и завершение игры через
  SIGTERM управляющему launcher: [Odin](odin-runtime.json), [Flip](flip-runtime.json).
  Это не проверка физического Exit. Обе БД прошли `quick_check=ok`;
  Odin оставлен с громкостью 0%.

## Границы

Пакеты подготовлены и установлены на две портативки; новый GitHub Release и
обновление публичного каталога не публиковались. Исходники отправлены в
`codex/golf-backend`; интеграция с другими ветками Crates остаётся отдельной.
Физические кнопки/звук, длительный FPS и разные интернет-сети этим прогоном
не проверены. [Парный casual-цикл от 26 октября](../lobby-devices-20261026/README.md)
сохраняется как прежняя приёмка, а не повторный тест версии 0.1.24.
