# Pocket Golf 0.1.22 — общие результаты через Backend

25 октября 2026. Подготовка в `codex/golf-backend`, база `5926385` с командами,
музыкой, анимациями и случайным соло-соперником. Опубликованный main `d88a855`
содержит более ранний 0.1.19 и не использовался как база окончательной реализации.
Публикация/GitHub push и портативки этим проходом не выполнялись.

## Доделано

Полный путь: существующий Lobby/group SDK → персональный вход участников в
серверный матч → проверка состава/Start → три настоящие лунки → одинаковые карточки
от всех → решение worker → общие рекорды/победы → новый матч при реванше.
Стороны корректно связываются и при ведущем не в первой команде; нормализация
чисел JSON проверена отдельно. 2/4 индивидуально, 4–8 командами по 2–3, общий мяч
и чередование сохранены. Соло/бот и передача контроллера не идут в общий зачёт.

Общие таблицы доступны из меню и итогов, по пять строк, с переключением режима/
метрики и страницами одной revision. Управление — обычные кнопки игры для
контроллера/клавиатуры/касания. Ошибки Backend не закрывают игровой транспорт.
Если не все участники имеют доступ, партия продолжается как casual без зачёта.
Повтор сохранённой карточки — явная команда с тем же operation UUID и только
под тем же Player. Смена владельца обрывает старые callbacks.

Правила `pocket-golf.island.analog5.v1` зарегистрированы на действующем Backend.
Три поля, 1–8 ударов, минимальный общий счёт. Хеши всех файлов симуляции и контента
проверяются при сборке. Протокол **pocket-golf.8** несовместим с `.7`.
Нужен SDK, объединяющий group `59755fc1` и Backend play `d6989438`;
подготовленное объединение — `e6824106`. На портативки оно не устанавливалось.

## Недоделано

Публикация/доставка в основном чате и реальный пользовательский путь на целевых
устройствах. Не проверены разные интернет-сети/NAT, физические контроллеры,
восемь устройств/FPS, финальная оценка звука/внешнего вида владельцем.

Trust — `peer_confirmed`, не серверное воспроизведение физики/античит/основание
экономических наград. Backend ещё не отдаёт публичные имена/аватары для таблиц:
пока `You` и сокращённые Player IDs. Восстановление игрового раунда, смена ведущего,
live join, рейтинг силы/Elo, сезоны/турниры/экономика не добавлены.

Следующий предметный блок серверной части: публичный игровой профиль (имя/аватар),
жизненный цикл его обновления/удаления и отображение в общих таблицах. Отдельно
остаётся усиление доверия результатам; это не автоматическая новая глобальная очередь.
Технический контракт и команды проверки: [SHARED_RESULTS](../games/pocket-golf/docs/SHARED_RESULTS.md).
