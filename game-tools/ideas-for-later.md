# Game Tools — Ideas for Much Later

These ideas have **not** been approved as individual projects or for development now. They are intentionally preserved **in one file**, to revisit much later.

- **Build Planner:** plan RPG character builds and attributes.
- **Crafting Calculator:** calculate required ingredients and resources.
- **Boss Notebook:** manual notes on bosses and tactics.
- **Map Pins:** annotate screenshots of in-game maps.
- **Quest Checklist:** manually track quests, goals and collectibles.
- **Save Inspector:** read-only comparison of supported saved-game versions, subject to exact-game format support.
- **Controls Cheat Sheet:** a user-made gamepad/keybind reference in game context.
- **Racing Telemetry:** optional lap and instrument display where real game data is exposed.
- **Party Notes:** shared notes tied to an active multiplayer session, if a suitable approved collaboration channel exists.

Do not create separate folders or implementation tasks for these until explicitly selected.
