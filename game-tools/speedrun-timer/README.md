# Speedrun Timer

**Type:** Game Tool for TrainerOS  
**Status:** Selected concept, not implemented.

A lightweight speedrunning timer that can be attached to a game.

## Initial scope

- Time a run and optional user-defined splits.
- Store local personal bests.
- Show a compact interface in permitted game context.

## Integration notes

Initially manual start/stop/splits; automated timer triggers require verified game integration, not imagined telemetry.
