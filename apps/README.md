# Apps

Independently usable applications suitable for the TrainerOS Apps area.

- [PixelPad](pixelpad/) — A small gamepad-friendly pixel art and sprite animation editor.
- [ChipTune Studio](chiptune-studio/) — A lightweight chiptune/music tracker for creating retro melodies and sound effects.
- [Pocket Radio](pocket-radio/) — A background-capable internet radio player.
- [Comic Shelf](comic-shelf/) — A gamepad-friendly comic, manga, and ebook reader.
