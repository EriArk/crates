# Pocket Radio

**Type:** App for TrainerOS  
**Status:** Selected concept, not implemented.

A background-capable internet radio player.

## Initial scope

- Listen to a personal list of internet stations.
- Maintain playback while using TrainerOS where audio policy permits.
- Optionally contribute a compact Start player widget.

## Integration notes

Use TrainerOS Media Session and audio focus instead of implementing separate system audio controls.
