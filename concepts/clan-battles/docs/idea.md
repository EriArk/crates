# Original Idea — Fluxer Clans

User concept: clans connected to Fluxer and battles between clans.

Likely fit: extend the existing opt-in community support for TrainerOS competitive mini-games, so communities can challenge and compete against other communities. Use existing Lobby, identities, social capabilities, and a single shared match-results model.

This is a **concept capture**, not a decision on scoring, clan authority, roles or transport.
