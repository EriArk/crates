# Original Idea — Achievement Coins

A playful TrainerOS-wide reward, tentatively called "coins", earned for beating games and unlocking RetroAchievements.

**Open question from the outset:** what would the player actually use them for?

Do not finalize the economy or award rates while the purpose remains unresolved. Potentially treat them as non-spendable personal progress, or use cosmetics only if that proves fun and useful.

Distinguish genuine verifiable achievement/completion signals from manual progress, and avoid counting duplicate provider events twice.

This document is an idea record, not implementation scope.
