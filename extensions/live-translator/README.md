# Live Translator

**Type:** Extension for TrainerOS  
**Status:** Selected concept, not implemented.

An optional in-game text/subtitle translation helper.

## Initial scope

- Translate selected on-screen text when a suitable capture/text source exists.
- Prefer offline/local processing where feasible.

## Integration notes

Requires real capture consent and supported languages; no automatic access to private messages or protected content.
