# Extensions

Optional extensions that compose the supported TrainerOS host mechanisms. They should not duplicate core systems or replace native platform services.

- [TATE Mode](tate-mode/) — Quick rotation/orientation setup for vertical arcade games.
- [Retro Shader Packs](retro-shader-packs/) — Optional visual shader collections for retro games.
- [Touch Mapper](touch-mapper/) — Controller-to-touch input mapping for games lacking native controller support.
- [Controller Overlay](controller-overlay/) — A small optional on-screen controller/help overlay during games.
- [Audio Profiles](audio-profiles/) — Optional presets for balancing game, background music and voice chat.
- [Save Journal](save-journal/) — A readable history of game save backups, with safe restoration when available.
- [Live Translator](live-translator/) — An optional in-game text/subtitle translation helper.
- [Dock Profiles](dock-profiles/) — Optional configuration presets for handheld versus connected-display setups.
- [Ghost Racing](ghost-racing/) — asynchronous recorded-run competition for compatible games.

**Core, not an extension:** performance profiles and gyro support are in [TrainerOS core proposals](../docs/traineros-core-proposals.md).
