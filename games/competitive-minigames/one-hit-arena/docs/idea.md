# One Hit Arena — Idea Notes

Compact platform arenas in which one precise hit eliminates an opponent. Very short rounds, roughly 15–30 seconds as an initial idea.

## Planned context

- Compact competitive mini-game for TrainerOS.
- One community per game.
- Fluxer/TrainerOS-integrated lobby and in-game social features.
- Use the same common integration approach as the other competitive mini-games.

**To decide later:** controls, game mechanics, match format, networking, UI, ranking and tournament details. See [shared approach](../../docs/shared-approach.md).
