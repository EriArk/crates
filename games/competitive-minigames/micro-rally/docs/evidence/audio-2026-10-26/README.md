# Звук и эффекты Micro Rally — 26–27 октября 2026

Финальный runtime: **`c3d38465c36f2ab0`**, Godot 4.7.2,
`build-manifest.json`. Экспортированы Windows x86_64, Linux ARM64 и Linux x86_64.
Сборка/проверки выполнены на существующем сервере; ПК использовался для рендера
готового Windows-экспорта. SDK/core/Lobby и портативки не изменялись.

- `audio_feedback_test.gd.log`: 0 ошибок. Декодирование/циклы, ровно три
  отсчёта и один GO, реакция двигателя/колёс/ускорения, офлайн-пауза и сетевое
  меню, последний круг/финиш/DNF без повторов, приглушение музыки, отдельная
  громкость и чтение сохранённых настроек, одинаковые снимки, бесшумный расход
  щита, лимит 12 голосов, 220 частиц и 96 следов, отсутствие следов в воздухе,
  их истечение и сброс реванша. Состояния для проверки событий заданы фикстурой.
- `drive_test.gd.log`: все **16 машин** физически продвигаются за 3600 шагов,
  0 ошибок, проверены восстановление и существующий бюджет эффектов.
- `sdk-16.log`: **3 passed / 0 failed**, 61,381 с. Настоящие SDK/PlatformHost,
  LobbyRuntime и TLS helpers, 16 процессов, 15 секунд езды, общий результат,
  реванш, отзыв профиля/выход, сохранение регистрации остальных участников.
  Финиш ускорен тестовой фикстурой; доставка сигналов провайдера подменена.
  Это не интернет, полный заезд 16 людей или замер портативной производительности.
  В финальном журнале нет SCRIPT ERROR / ERROR или предупреждений об утечках.

`journey_test.gd.log`, `network_test.gd.log`, `cup_journey_test.gd.log` —
0 ошибок на **`3e32ab1a54c42aab`**, см. `mix-build-manifest.json`: ввод/пауза,
стрельба, финиш/реванш, протокол и очереди, кубок/гараж/сохранение.
После них изменены только непрерывность следов, разрешённый экран захвата
настроек, дополнительные проверки и документация. Аудиокод, физика, сетевой
протокол, кубковые правила/сохранения не менялись.

Быстрые fixed-FPS тесты опережали реальный поток Dummy-микшера. Общий
`audio_drain.gd` удаляет игру и даёт этому потоку 180 мс на затухание/освобождение
голосов перед завершением процесса. Это исправление тестового завершения,
не задержка или новая пауза игрового цикла. Ранее сохранённые контрольные
снимки имели предупреждения выхода; выше приведён исправленный финальный прогон.

## Реальный выход микшера

`audio_mix_test.gd.log`, снимок **`3e32ab1a54c42aab`**: записан выход
внутренней шины после лимитера через AudioEffectRecord. Микрофон не используется,
вывод на динамики отключён. Сценарий: меню → отсчёт → движение/ускорение →
выстрелы/щит/удар → последний круг → победа. Физическое движение здесь заменено
состояниями для проверки звука; PCM действительно создан движком.

- Длительность: **19,226 с**; PCM: **3 391 488 байт**.
- Пик: **−14,164 dBFS**, RMS: **−29,315 dBFS**, клиппинга в этой записи нет.
- Громкость: музыка 50%, эффекты 75%. Это один сценарий, не анализ всех
  возможных сочетаний. Ограничитель −1 dB действует также в самой игре.
- WAV сохранён как `audio-preview.wav` в серверных экспортах этого снимка;
  копия для владельца — `build/rally-audio-preview/audio-preview.wav`.

Это подтверждает декодирование и выход микшера. Субъективное прослушивание,
баланс на динамиках портативок/в наушниках и оценка музыки владельцем остаются
отдельной приёмкой. Исходные записи авторов и лицензии описаны в
[реестре аудио](../../../assets/audio/README.md).
