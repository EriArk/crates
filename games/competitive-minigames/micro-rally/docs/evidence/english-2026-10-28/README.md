# Английский интерфейс Micro Rally — 28 октября 2026

По запросу владельца игровой интерфейс переведён на английский:
главное меню/каталог, кубки/гараж/награды/результаты, HUD, условия/боты,
настройки/управление/вибрация, подтверждения, ошибки сохранения и сообщения
сетевого заезда/SDK-подключения. Названия трасс: Dirty Valley, Quarry,
Forest Pass, Nordschleife; первый кубок — Woodland Challenge.
Название окна и будущего пакета — `Micro Rally (alpha)`.

249 уникальных строк. Статический просмотр 2318 строковых литералов scripts/
и addons/traineros не нашёл кириллицы, U+FFFD или повреждённых разделителей.
Сохранены стрелки, знаки ©/×/∞ и атрибуция лицензий. Очки форматируются с точкой
(`112.5`), идентификаторы/схемы/папки сохранений не изменены. Пользовательские
имена SDK не переводятся. Документация проекта по его правилам остаётся русской.

## Проверки

- `menu_test`: все меню/контролы укладываются в 1280×720; выбор контроллером,
  возврат/фокус, ползунки, подтверждения и вызов существующего лобби работают.
- `cup_test` и `cup_journey_test`: арифметика наград/очков, запись/повтор,
  этапы, состав и профиль сохраняются после перевода.
- `difficulty_test`, `journey_test`: настройки ботов, ввод и пауза сохранены.
- `audio_feedback_test`, `haptics_test`, `network_test`: сообщения/названия
  не меняют поведение звука, вибрации и контракт 16 участников.
- Восемь разных сценариев прошли. Физические контроллеры, звук, FPS портативок
  и живой интернет-матч в эти проверки не входят.

`integration-manifest.json` — a59fd235b98ffa99. После него исправлены символы
стрелок в схеме клавиатуры и десятичная точка очков. Окончательный
`build-manifest.json` — **e45698c052bb9dd1**, повторные menu/cup проверки
и экспорты Windows, Linux ARM64, Linux x86_64. Полные заезды физики описаны
в [проверках шин](../tires-2026-10-28/README.md): после их снимка runtime
менялся только в отображаемых строках и окончаниях строк, что записано
в localization-audit.json.

Кадры из экспортированного x86_64 сняты на серверном software OpenGL,
1280×720; это проверка оформления, не портативной производительности.
