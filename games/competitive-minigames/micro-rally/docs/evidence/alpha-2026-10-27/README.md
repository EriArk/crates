# Micro Rally (альфа) — публикация и портативки, 27 октября 2026

По прямому разрешению владельца опубликована **0.1.0**, с названием
**Micro Rally (альфа)** в Crates, записи пакета, окне и главном меню.
[GitHub Release](https://github.com/EriArk/crates/releases/tag/micro-rally-v0.1.0)
содержит ARM64/x86_64 пакеты, соответствующий архив исходников, записи пакетов,
SHA256SUMS и манифест сборки. GitHub Actions не использовался.

Исходный коммит: `a2e6b5fa377cc1abdb05a8821762c7e1e321dc45`.
Серверный снимок Godot 4.7.2: `574e9a7e102c65dd`.
Проверки аудио/эффектов и пути кубка прошли после переименования.
В пакетах сохранены GPL, Godot и сторонние лицензии; версия опубликованных
байтов неизменяема. Полный кубок не заявлен: открыт только первый этап.

## Каталог и загрузка

Подписанная ревизия **37** добавляет игру в `whats-new` и `arcade`, сохраняя
прочие проекты/версии и оформление. Изображение — настоящий кадр игры.
Ключ подписи остался на машине владельца вне Git/сервера; на сервер передан
только подписанный снимок. Активация выполнена под существующей блокировкой
публикации с проверкой предыдущей ревизии и атомарной заменой.

`publication.json` подтверждает повторное чтение публичного HTTPS endpoint
штатным User-Agent, Ed25519-подпись, обе архитектуры и русское название.
На обеих портативках **установленный штатный catalogue.py** синхронизировал
каталог, а **установленный installer.py** скачал ARM64-пакет по публичному
GitHub URL, проверил размер/SHA-256 и активировал его. Архив не подменялся
локальной копией. Само нажатие кнопки Download в QML этим не проверялось.

## Устройства

| Проверка | Odin 2 | Retroid Pocket Flip2 |
| --- | --- | --- |
| Публичная загрузка и установка 0.1.0 | Да | Да |
| Главное меню с пометкой «альфа» | [Кадр](odin-menu.png) | [Кадр](flip-menu.png) |
| Обычный managed launcher под выбранным Trainer | Да | Да |
| Завершение launcher/игры, работающая оболочка | Да | Да |
| Старые receipts/objects/файлы данных сохранены | Да | Да |

Отчёты: `odin-installation.json`, `flip-installation.json`,
`odin-acceptance.json`, `flip-acceptance.json`, `final-state.json`.
Установленные helpers и оболочки не заменялись. Громкость не менялась:
Odin оставлен на 0%, Flip — на имевшихся 20%.

На Flip через 18 секунд был ещё [экран загрузки](flip-menu-initial.png).
Повторная проверка без переустановки дала реальное меню при захвате через
50 секунд; точное время готовности между кадрами не измерялось. В командной
строке процесса подтверждён `--rendering-method gl_compatibility` — локальный
для Flip2 fallback из launch.sh. Odin использует настройку Mobile по умолчанию.
Release-сборка не пишет renderer в stdout, поэтому `renderer: unknown` в
автоматическом отчёте не заменён догадкой. Кадры просмотрены отдельно.

Проверка подтверждает установку, отрисовку меню и managed stop. Физические
кнопки, прослушивание, долгий FPS, гонка и полный сетевой путь на устройствах
оставлены владельцу для альфа-проверки. Это не приёмка 16 портативок или интернета.
