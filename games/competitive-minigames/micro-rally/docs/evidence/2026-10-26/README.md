# Проверки первого участка — 26 октября 2026

- `natural-frame.png`, `render.log`: реальный Windows Vulkan Mobile кадр,
  снимок исходников `8545c8b2154c53c9`, GTX 1660 Ti, 1280×720, 16 машин,
  счётчик 60 FPS на момент захвата. Это не длительный замер и не портативка.
  Позднее изменены привязки ввода/барьер паузы и расчёт разрешения; палитра,
  материалы и освещение этого кадра сохранены.
- `drive.log`: 4000 физических кадров, все 16 машин продвинулись по маршруту,
  0 ошибок проверок. Последующие изменения затронули только сценарий теста
  ввода и средство выбора теста, не физику или игровой код.
- `journey.log`: синтетические события viewport/клавиатуры, меню, пауза,
  отпускание удержанного газа, выстрел через физический raycast, щит,
  восстановление, финиш, локальная запись и реванш — 0 ошибок проверок.
- `build-manifest.json`: итоговый серверный снимок `310e8d30ce4f79e2`,
  экспорт Windows x86_64, Linux ARM64 и Linux x86_64.

Остаются: качество управления реальным геймпадом, длительная гонка/боты,
загрузка и FPS портативок, SDK-аватар с выражениями, сеть на 16 участников,
полный кубок и публикация. При завершении headless-проверки Godot сообщает
о нескольких ObjectDB-объектах при выходе; это ещё не разобрано.
Владелец отклонил предыдущую чрезмерно контрастную палитру; новый кадр не
является утверждённым совпадением с концептом.
