# Вибрация и Лесной перевал — 28 октября 2026

Выполнено в отдельной ветке `codex/micro-rally`. Экспорты и Godot 4.7.2
запускались на сервере, без публикации Crates и без доступа к портативкам.

## Реализация

- [Вибрация](../../HAPTICS.md): настройка профиля, смешивание импульсов, остановка
  при паузе/потере фокуса/смене контроллера. Записаны вызовы аппаратной границы,
  реальные моторы не включались и не проверялись.
- [Перевал](../../PASS.md): третий этап, пять кругов по 1468,19 м, перепад 32,82 м,
  рассвет/дождь. Существующий кубок, состав и два результата сохраняются.
- Дорожная геометрия Перевала и Карьера обрезается по треугольникам земли;
  это устраняет найденное на рендере проступание грунта между вершинами.

тесте — фикстуры; Перевал проезжался целиком с общей физикой и оружием.
Начальные четыре круга дали 7:58,5 у игрока-бота; для кубкового темпа дистанция
увеличена до пяти. В отдельных заездах осталось четыре круга.

`final-manifest.json`: **a73e33beccd20a28**, финальные Windows / Linux ARM64 /

дорожной сетки, проверки её внутренности, статическая постановка машин для

## Кадры

Кадры экспортированной игры на изолированном дисплее сервера, 1280 × 720,
программный Mesa/Vulkan (`mobile`) либо Mesa/OpenGL (`gl_compatibility`).
Они проверяют видимость дороги и меню, **не производительность портативок**.
Кадры с `at` — статическая расстановка машин на указанной точке маршрута,
не снимок доказанного ручного заезда. В тестовом окружении без активного SDK
профиля кресло пустое; это ожидаемое поведение, проверенное предыдущим блоком.
