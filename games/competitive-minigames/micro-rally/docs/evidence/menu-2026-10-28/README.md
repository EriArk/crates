# Игровое меню Micro Rally — 28 октября 2026

Реализация в ветке `codex/micro-rally`, исходная база `c5bf0e2`. Проверки,
экспорты и рендер выполнялись на сервере с Godot 4.7.2. Публикации Crates,
установки, портативных замеров и аппаратной приёмки не было.

## Результат

- Главное меню: Кубки, Быстрая игра, Лобби, Гараж, Настройки, Выход;
  отдельное продолжение при незавершённом кубке. Машина отражает выбор профиля.
- Каталог по реестру с фильтрами/страницами; экран первого кубка с четырьмя
  этапами и наградой. Реестр позволяет расширять представление, но текущая
  реализация карьеры/хранилища по-прежнему обслуживает один первый кубок.
  Добавление нового вида серии потребует его правил и привязки запуска.
- Три режима: гонки, сражения на аренах, батлрояль. Только гонки доступны
  для запуска; будущие режимы подписаны «готовится», отключены и пропускаются
  при перемещении фокуса. Это не реализация новых боевых режимов.
- «Лобби» использует прежний `activity.open` SDK. Самостоятельный запуск
  сообщает, что лобби доступно при запуске через TrainerOS. Собственного
  списка сетевых комнат или логина не добавлено.
- Настройки имеют отдельные звуковые ползунки, изменение коробки/вибрации
  влево/вправо и схему управления. Они возвращают игрока в исходный экран;
  меню из паузы не возобновляет гонку при нажатии «Назад» внутри настроек.
- Выход, перезапуск и замена текущего кубка требуют явного выбора;
  подтверждение начинает с отмены/сохранения текущего зачёта.
- Сохранены управление гонкой, SDK-аватар, существующие результаты, награды,
  правила и физика. Курсивный шрифт Roboto Condensed включён с SIL OFL;
  источник и SHA-256 находятся в `assets/fonts/README.md`.

Linux x86_64 записаны в `build-manifest.json`; после изменений подтверждения,
страниц каталога, шрифта/тени и выделения ползунков `menu_test` выполнен повторно:
**0 ошибок**. `source-check.json` сверяет файлы runtime с окончательным снимком.

Финальный экспорт **8cd0e4f8ca8c18f9** (`package-manifest.json`) отличается
от проверенного runtime только `export_presets.cfg`: добавлено включение
лицензии шрифта и его атрибуции в пакеты. `package-check.json` фиксирует
одинаковый runtime и наличие `assets/fonts/OFL.txt`/`README.md` в журналах
упаковки всех трёх платформ. Повторные гонки после изменения фильтра файлов
не выполнялись; новой публикации пакетов нет.

Кадры: [главное меню](main.png), [звук](audio.png), [этапы кубка](cup.png),
[подтверждение](confirmation.png). Это программный серверный рендер OpenGL
1280×720 снимка `ed37eeac1d738475`. Они проверяют оформление
и компоновку, **не FPS или графическую производительность портативок**.
Проверка очереди SDK не является новым доказательством открытия реального
авторизованного лобби, сетевого кубка или интернет-игры. Полная ручная навигация,
сенсорный экран и физические кнопки на устройствах остаются отложены.
