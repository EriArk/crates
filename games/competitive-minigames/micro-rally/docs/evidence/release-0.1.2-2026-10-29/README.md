# Micro Rally (альфа) 0.1.2 — опубликована 29 октября 2026

По прямому разрешению владельца опубликован [GitHub Release 0.1.2](https://github.com/EriArk/crates/releases/tag/micro-rally-v0.1.2)
и активирована подписанная ревизия **39** каталога Crates (предыдущая — 38).
Название **Micro Rally (альфа)** сохранено, игра поднята в новинках/аркадах.
Все прежние записи пакетов, другие проекты и оформление сохранены.

Исходники **2b7f101c53c80caab062a42cc77970caa398f20e**, серверный снимок
**4a9d760378188762**, Godot 4.7.2. ARM64 и x86_64 собраны и упакованы на сервере.
Release содержит два Linux-пакета, соответствующие исходники, лицензии,
записи установщика, манифест и SHA256SUMS. Пакеты неизменяемые.

[publication.json](publication.json) подтверждает:

- Публичное скачивание обоих пакетов: размеры и SHA-256 совпадают с записями.
- Публичный архив исходников совпадает по SHA-256.
- Свежий HTTPS snapshot прошёл проверку Ed25519 штатным модулем каталога.
- Обновление 38 → 39 пришло как delta и восстановило тот же проверенный снимок.
- Старые записи пакетов сохранены; русское название с пометкой «альфа» сохранено.

Каталог подписан существующим ключом владельца; ключ не передавался на сервер
и не включён в репозиторий. Активация под publish.lock проверила прежнюю ревизию
и атомарно заменила снимок. GitHub Actions не использовался.
Первичная финальная проверка неверно передала оболочку HTTP snapshot в проверку
самой подписи; после применения штатного `catalogue.apply` полный и инкрементальный
ответы успешно проверены. Каталог повторно не публиковался.

## Содержание

Четыре этапа одиночного Woodland Challenge с Nordschleife в финале, Rust Pit,
Battle Royale на Deadwater 900×700 м, новая подвеска/шины, боты/сложность,
ручная коробка/вибрация, пять камер и общий SDK-аватар с новыми костюмами/эмоциями.
Интерфейс английский. [Release notes](release-notes.md).

Протокол `micro-rally.8`: всем участникам нужно обновиться. Через Lobby доступны
гонка в Долине, арена и Battle Royale. Сетевой кубок ещё не реализован.
Подтверждения реализации и кадры: [камеры, SDK, Deadwater](../deadwater-sdk-camera-2026-10-29/README.md).
Повторный camera_test прошёл на опубликованном снимке; прочие неизменённые
реализации опираются на сохранённые проверки, а не на выдуманный новый прогон.

## Границы доставки

При публикации на устройства не подключались. Подписанный
каталог позволяет обычной системе Crates обнаружить обновление; нажатие Update
и автоматическая установка на конкретной портативке в этом проходе не проверялись.
Физические кнопки, производительность, звук, комфорт камер и полный сетевой
игровой путь остаются отдельной приёмкой. Публикация не подтверждает игру
через разные интернет-сети. Оформление и баланс Deadwater продолжаются.


## Установка по последующему разрешению владельца — 29 октября

**0.1.2 установлена на Odin 2 и Retroid Pocket Flip2.** Использованы установленные
штатные `catalogue.py` и `installer.py`: загрузка по публичному URL, SHA-256,
атомарная активация и проверка receipt. Сохранены старые объекты, все прежние
файлы данных (сверены хеши) и receipts других приложений.
[Odin](devices/odin/installation.json), [Flip](devices/flip/installation.json).

По просьбе владельца выполнена только установка: игра не запускалась, меню,
FPS, кнопки, звук и геймплей не проверялись. Процесс оболочки на каждом устройстве
остался тем же; громкость и SDK/оболочка не менялись. Игровую проверку проводит владелец.
