# Micro Rally (альфа) 0.1.3 — опубликована и установлена 29 октября 2026

По запросу владельца опубликована [0.1.3](https://github.com/EriArk/crates/releases/tag/micro-rally-v0.1.3)
и подписанная ревизия **40** каталога Crates (предыдущая 39). Название с пометкой
«альфа» сохранено; другие игры и старые пакетные записи сохранены.

Исходный commit `789488be50ebc930f168ae44edc76c8e4ad4798c`, серверный снимок
`973cfbac4f4a44a8`, Godot 4.7.2. Исполняемый код/шейдеры/активы/SDK-потребитель
побайтно совпадают с проверенным `b3a2a6730fd3cb2c`; изменены материалы релиза.
[Проверки реализации](../feel-2026-10-29/README.md), [состав](release-notes.md).
Windows, Linux ARM64 и x86_64 экспортированы на сервере; Linux-пакеты и исходники
там же упакованы. Сборки/пакеты не создавались на портативках.

[publication.json](publication.json): публично скачаны и сверены SHA-256/размеры
ARM64, x86_64 и архива исходников. Проверена подпись свежего каталога и delta
39 → 40; результат совпадает. Активация под publish.lock проверила предшествующую
ревизию, старые записи сохранены. Секрет подписи не включён в артефакты.
GitHub Actions не использовался. [Манифест](build-manifest.json), [хеши](SHA256SUMS).

## Портативки

**Micro Rally 0.1.3 установлена на Odin 2 и Retroid Pocket Flip2** через штатные
`catalogue.py`/`installer.py`, из публичного каталога. Перед установкой подтверждены
модели устройств, прежняя 0.1.2 и отсутствие запущенной Micro Rally.

- [Odin: установка](devices/odin/installation.json), [лог](devices/odin/install.log).
- [Flip: установка](devices/flip/installation.json), [лог](devices/flip/install.log).

Receipts совпали с новым публичным ARM64 SHA-256. Все прежние файлы данных
сохранились с теми же хешами, прежние объекты и receipts других приложений
сохранены. Процессы оболочки не менялись. Громкость, SDK и оболочка не обновлялись.

**Только установка:** игра не запускалась, FPS/кнопки/звук/геймплей не проверялись.
Игровую приёмку проводит владелец. Это не подтверждение разных интернет-сетей.
Протокол `micro-rally.9`: всем участникам нужно обновление. Сетевой кубок
остаётся следующей работой после обратной связи по балансу/производительности.
