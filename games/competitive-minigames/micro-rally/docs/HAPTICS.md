# Вибрация контроллера

28 октября 2026. Локальная обратная связь Micro Rally, без изменения SDK или
сетевого протокола micro-rally.4. Из меню или паузы: `Управление → Вибрация`.
Четыре значения: выключена, слабая, обычная (по умолчанию), сильная.
Выбор сохраняется отдельно для каждого профиля.

Короткие импульсы сопровождают столкновение/урон, приземление, фактический
выстрел, переключение передачи и удар по щиту. Лёгкий фон передаёт занос и
ускорение. Нажатая стрельба без выстрела при перегреве молчит; обычное убывание
щита не считается попаданием. События берутся только с машины местного игрока,
в том числе из состояния ведущего в сетевом заезде.

Слой haptics.gd смешивает огибающие по максимуму каждого мотора, без суммирования
до постоянной максимальной тряски. Сила ограничена 0–1; максимум 30 команд/с.
Каждая команда имеет срок 100 мс, поэтому остановка кадров не оставляет мотор
включённым навсегда. Пауза, сетевое меню, потеря фокуса, финиш, смена профиля,
возврат машины, смена/отключение контроллера и выход отменяют эффекты. Новый
контроллер получает свежую исходную телеметрию без повторения старых ударов.
Устройство без доступной вибрации безопасно остаётся без неё.

Использованы штатные [Input.start_joy_vibration / stop_joy_vibration](https://docs.godotengine.org/en/stable/classes/class_input.html)
и сведения Godot о [поддержке геймпадов](https://docs.godotengine.org/en/stable/tutorials/inputs/controllers_gamepads_joysticks.html).
Слабый/сильный каналы относятся к обычным моторам контроллера; адаптивные курки
и детальная тактильная отдача DualSense в эту реализацию не входят.

haptics_test подменяет только границу аппаратных вызовов и проверяет реальные
события, смешивание, ограничения и жизненный цикл. Это проверка кода, не ощущений
в руках: сила, поддержка драйвером и удобство на Odin/Flip ещё не проверены.
Портативки, публикация и установка остаются отложены владельцем.
