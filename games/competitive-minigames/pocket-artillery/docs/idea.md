# Pocket Artillery — Idea Notes

Two or more players choose firing angle and power, then shoot across destructible terrain. Turn-based gameplay could need relatively little real-time synchronization.

## Planned context

- Compact competitive mini-game for TrainerOS.
- One community per game.
- Fluxer/TrainerOS-integrated lobby and in-game social features.
- Use the same common integration approach as the other competitive mini-games.
