# Optional Fluxer Community Support for Competitive Mini-Games

**Approved direction:** Each competitive mini-game has its official/default game community, **but is not limited to it**.

Any existing Fluxer community should be able to **opt into supporting these games**, if its authorized moderators/administrators enable that feature and the account/bot integrations actually have the permissions required to manage channels. Enabling it creates the needed supporting subchannels/categories, respecting that community's existing structure and access rules.

## Expected use

- A player can select the supported community context for a compatible mini-game, not just the primary/default community.
- The community can offer places for game lobbies, challenges, results and competitions using the same shared game infrastructure.
- Do not require a new Fluxer community for each installation or a second TrainerOS Lobby.
- Discover and display only the communities in which that user is actually authorized to participate.
- A community opt-in does not mean public access to private data or automatic administration rights.


## Possible future clan competitions (concept only)

Fluxer-based clans and battles between them have been proposed as a further use of communities. Opted-in communities could challenge one another in compatible mini-games and share standings across matches using the existing Lobby/results systems. How clan membership, challenges and scoring work is **not decided**.

See [Fluxer Clans & Clan Battles](../../../concepts/clan-battles/).

## To decide later

- Whether support is enabled globally for the collection, per game, or both.
- Exact channel/category template, names, bot setup and deletion/disable lifecycle.
- How standings and tournaments are scoped across official vs community-specific contexts.
- Membership discovery, moderation and authorization UX.
- Which parts use Fluxer directly versus TrainerOS coordination, within verified provider limitations.

Keep setup as simple as possible for community owners. No mandatory new server or account per community.
