# Interactive Game Shows

A new family of TrainerOS/Fluxer multiplayer experiences involving a **host/presenter** and a **participating audience** from the existing Lobby spectator seats.

- [Audience Game Show](audience-game-show/) — first concept, inspired by interactive television shows such as Hugo (without copying an existing game's assets or branding).

**Status:** Concept category; deeper mechanics and shared platform support to be discussed.
