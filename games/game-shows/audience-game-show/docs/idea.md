# Audience Game Show — Original Idea

A host-led interactive show in which participants who joined the existing TrainerOS Lobby as spectators can **actively participate in minigames**.

- One host leads the experience.
- Spectators become an interactive audience for the show, with game-specific interaction when a round allows it.
- Conceptually related to Hugo-style TV participation and game shows.
- Reuse TrainerOS Lobby, Fluxer Social and a shared small-game platform where useful.

Unresolved: audience input protocol, game formats, stream latency, number of participants, host tools, points, cheating protections, and UI. Keep it a separate concept until those are discussed.
