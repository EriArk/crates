# Audience Game Show

**Type:** Multiplayer game/show concept for TrainerOS.  
**Status:** Selected concept, not implemented.

One person leads or hosts an interactive game show. Other people can join as **spectators in the normal TrainerOS Lobby**, but those spectators can also take part in short minigames, answer prompts, vote or influence what happens on the show.

Hugo-style interactive TV/game shows are the inspiration for the format, not a request to copy the original intellectual property.

## Core ideas

- One host/presenter controls the show flow.
- Audience members use the existing Lobby spectator participation context — no parallel social app or second Lobby.
- Different short minigames can allow different audience actions (inputs, reactions, choices or team play).
- Show the audience and relevant participation inside the running show, instead of forcing Social navigation.

**Open:** whether and how temporary active audience participation differs from ordinary player seats, how simultaneous inputs are resolved, scoring, fairness, audience scale, networking and TV/stream presentation. These require a later shared-design discussion; being a spectator currently does not imply an implemented input channel.
