# Widgets

Small Start → Extensions contributions for TrainerOS. Each approved concept has its own folder.

- [Game Roulette](game-roulette/) — A small Dashboard widget that picks a random game from the user's installed library.
- [Friend Radar](friend-radar/) — A compact view of friends' current game activity and potential multiplayer opportunities.
- [Arcade Today](arcade-today/) — A Dashboard card featuring a daily challenge from the competitive mini-games collection.
- [Tournament Live](tournament-live/) — A compact view of active game tournaments.
- [Quick Notes](quick-notes/) — A tiny notepad available in Start → Extensions.
- [Achievement Hunt](achievement-hunt/) — A widget surfacing unfinished RetroAchievements goals for games the user plays.
- [Controller Monitor](controller-monitor/) — A small status card for connected game controllers.
- [Session Timer](session-timer/) — A simple gaming-session timer and optional break reminder.
- [Screenshot Frame](screenshot-frame/) — A rotating picture-frame widget for the user's own game screenshots.
- [Backlog Dice](backlog-dice/) — A random picker for the user's personal 'play later' list.
- [Music Radio](music-radio/) — one universal radio-style widget for likes, playlists and service-generated recommendations across connected music services.
