# Game Roulette — Agreed Idea

A small Start → Extensions widget with **one big "Surprise Me!"** button.

- Tap it with the gamepad.
- Covers from the user's available/launchable game library cycle briefly in a playful roulette animation.
- The widget shows one random game and allows a deliberate **Play** action through TrainerOS's usual game launcher.
- Tapping again rerolls.
- Do not launch while the animation spins; selection is not launch confirmation.

**Initial scope:** All currently available and launchable games in TrainerOS. Empty library gets a clear empty state. No new game-scanning system.

**Deferred, not approved for MVP:** platform/collection/backlog filters, elaborate configuration, extra effects or gamification.

**Status:** Basic UX approved, implementation not started.
