# Game Roulette

**Type:** Widget for TrainerOS  
**Status:** Selected concept, not implemented.

A small Dashboard widget that picks a random game from the user's installed library.

## Initial scope

- One-button random selection of an installed game.
- Show the chosen game and allow the user to launch it.

## Integration notes

Use existing TrainerOS Games identities and launch routes rather than scanning libraries independently.
