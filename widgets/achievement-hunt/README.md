# Achievement Hunt

**Type:** Widget for TrainerOS  
**Status:** Selected concept, not implemented.

A widget surfacing unfinished RetroAchievements goals for games the user plays.

## Initial scope

- Show a small set of not-yet-unlocked achievements.
- Open the appropriate game's achievements/context.

## Integration notes

Use confirmed RetroAchievements data; do not invent progress metrics that the provider does not expose.
